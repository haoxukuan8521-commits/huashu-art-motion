# 样镜复评 · 屋脊神兽 v7

核对的是这一轮编码后的成片。片长 27.0 秒。口播音轨按比特流原样接回，校验和与上一版相同。十一只走兽和正吻稿没有改像素。正吻与正脊的相接、檐口收线保持上一版。

## 这一轮改了什么

0 到 1.3 秒贴在仙人、龙、凤上，兽高约 500px，背后是大片浅空。76px 的「屋顶上，谁在排队？」在 0.2 到 0.6 秒淡入，底部原字幕不动。1.3 到 2.7 秒缓推回全屋，正吻在 2.40 到 2.98 秒淡入，4.3 秒两只都在画内，并留到全景结束。

21.8 秒起，右侧一块约占画面 48% 的示意板代替原来的角落小图。屋面稍稍让开，走兽不改。瓦片用大约 13px 滑入，钉子随后从瓦下长出。字是「脊瓦」「固定钉」74px，「固定方式示意」56px。

屋面瓦垄改成错开的短曲线，不再是通长的直线格子。线仍裁在檐口内。
